A program that writes one brutally honest line — what an AI agent prints
the instant it breaks production — to `/output/entry.txt`, for the make.fun
bounty
[Break Production, Own It](https://make.fun/bounty/u-ricoxyz-break-production-own-it-be78a994).

Run it with `python3 main.py`; it writes the line to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
